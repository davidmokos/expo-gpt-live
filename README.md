# Live

An Expo SDK 57 voice app with GPT-Live 1, native audio, and six [AI Elements Persona](https://elements.ai-sdk.dev/components/persona) variants. You can speak during replies, choose a voice, and keep an iPhone conversation running in the background.

https://github.com/user-attachments/assets/dd22258b-18b2-48fb-9d93-4a928df576cc

## Get started

You need Node.js 22.13+, macOS with Xcode 26.4+, and an OpenAI API key with access to GPT-Live 1.

```sh
git clone https://github.com/davidmokos/expo-gpt-live.git
cd expo-gpt-live
npm ci
npm run setup
```

Add your key to `OPENAI_API_KEY` in `.env.local`. Setup creates the app's access token and local server address. It preserves an existing `.env.local`.

Set `ios.bundleIdentifier` in `app.json` to your own identifier, such as `com.yourname.live`. Keep your Mac and iPhone on the same Wi-Fi. Connect and unlock the phone, trust the Mac, and enable Developer Mode in iPhone settings. Then run:

```sh
npm run ios:device
```

Expo handles signing, installation, and the development server. For later JavaScript changes, run `npm start`. Use `npm run ios` for a simulator. Expo Go cannot run this app because WebRTC and Rive require a native build.

For a browser, run `npm run web` and enter the `API_TOKEN` value from `.env.local` when you tap Start. Use `npm run android` for Android; background calls are implemented on iOS only.

## Environment

`.env.local` is ignored by Git.

| Variable                | Used by                                                                     |
| ----------------------- | --------------------------------------------------------------------------- |
| `OPENAI_API_KEY`        | Server only. Your OpenAI key.                                               |
| `API_TOKEN`             | Server. Generated by setup.                                                 |
| `EXPO_PUBLIC_API_TOKEN` | Native app. Must match `API_TOKEN`.                                         |
| `EXPO_PUBLIC_API_URL`   | Native app. Your Mac's reachable address on port 8088, or a hosted API URL. |

Never put the OpenAI key in an `EXPO_PUBLIC_` variable. The app's shared token is for local development and private builds. Add user authentication before making the backend public.

For an app that works without your Mac, follow [EAS deployment](docs/deploy.md). The template has no linked EAS project.

## Development

```sh
npm run check
npm run format
```

The screen is in `src/screens/live-screen.tsx`. Native controls and Persona renderers are in `src/components`. Call lifecycle and transports are in `src/live`; the server route uses `src/server/live-session.ts`.

Voices are fixed for each call. Persona choices can change at any time. Both choices are saved locally. Calls end after ten minutes; this does not enforce an account spending limit.

See [dependency notes](docs/dependencies.md) for the Xcode workaround and an upstream advisory.
